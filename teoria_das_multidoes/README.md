# Sabedoria das Multidões — Estimativa de Ovos no Pote

Este projeto demonstra, de forma prática e estatística, o conceito de sabedoria das multidões, analisando palpites de colaboradores sobre a quantidade de ovos em um pote.

## Objetivo

Investigar se a média ou mediana dos palpites de um grupo se aproxima mais do valor real do que a maioria das estimativas individuais, validando o fenômeno da sabedoria das multidões.

## Como Executar

1. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```
2. Certifique-se de que o arquivo de dados `Quantos ovinhos tem na cesta_2025.xlsx` está na mesma pasta do notebook.
3. Execute o notebook `Teoria_das_multidoesv2_melhorado.ipynb` célula por célula.

## Principais Resultados
- A média coletiva superou mais de 70% dos palpites individuais.
- Redução significativa do erro em relação ao participante médio.
- Robustez estatística comprovada por simulações e diferentes métodos de agregação.

## Expansão Sugerida
- Aplicar o método em outros contextos de estimativa coletiva.
- Coletar dados online e atualizar a análise em tempo real.
- Criar dashboards interativos para visualização dos resultados.
